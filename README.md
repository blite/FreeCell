# FreeCell → Solitaire

The FreeCell repo, and its GitHub Pages site, became
[blite/Solitaire](https://github.com/blite/Solitaire) on 2026-10-21. GitHub Pages
doesn't follow a repo rename, so this repo only forwards every old
`blite.github.io/FreeCell/…` address — in shipped apps' Settings and App Store
listings — to the same page at `blite.github.io/Solitaire/…`. FreeCell 1.0's
root `/privacy/`, `/terms/` and `/support/` go to `/freecell/…`. Keep it.
